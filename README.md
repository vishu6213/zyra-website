# ZYRA — Next-Gen AI Desktop Cyber Companion

A complete, high-fidelity local clone of the cinematic landing page at `https://string-tune.fiddle.digital/`, reimagined for **ZYRA** (Next-Generation AI Desktop Cyber Companion & Autonomous Cyber Agent by Vishvajeet Tiwari).

All original scroll transitions, WebGL 3D scenes (the interactive 3D Katana, dynamic storm particle canvas, Japanese cloud scenery, and red bonsai daisho showcase), audio/video playback, and interactive cursor/hover physics are 100% preserved. All copy, narratives, dialogues, badges, and modals have been transformed into Zyra's features and capabilities.

## Quick Start

Requires Node.js 18+.

```bash
# Start the static local server
npm start
```

Then visit **http://localhost:4173** (or double-click `start.cmd` on Windows).

## Preserved Motion & Technologies
- **3D Katana WebGL Hero**: Three.js GLTF/GLB models with PBR textures and HDR environment lighting.
- **Dynamic Canvases**: Interactive storm particle physics canvas, Japanese cloud landscape, and red bonsai tree.
- **Scroll Synchronization**: Progress-linked clip masks, split text character kerning, SVG path morphing, and virtual wheel interpolation.
- **Reactive Nuxt/Vue Hydration**: Vue 3 template state and SSR HTML synchronized without layout shifts or hydration flash.
